02

Capture Every Thought

Press Ctrl+N or click + New Note to create a note. Write freely in Markdown — it's just text that looks beautiful when rendered.

  • Title bar — Give your note a name
  • Toolbar — Bold, italic, headings, code blocks
  • Edit / Preview / Split — Three writing modes
  • Auto-save — Changes save automatically

03

Connect Ideas with Links

Type [[Note Name]] anywhere in a note to create a link to another note. A dropdown autocomplete appears as you type.

  • Bi-directional — Backlinks tracked automatically
  • Autocomplete — Suggestions appear as you type [[
  • Backlinks panel — See every note that links here
  • Click any link — Instantly navigate to that note

04

See Your Mind in 3D

The Knowledge Graph shows your notes as glowing spheres in 3D space. Links between notes are glowing beams of light.

  • Left-drag — Orbit around your knowledge galaxy
  • Scroll — Zoom in and out
  • Click a node — Open that note instantly
  • Hover — See note title and tags
  • Filter — Search and isolate specific nodes

05

Organise with Tags

Tags let you group notes by topic, project, or any category you define. Filter your entire vault with a single click.

  • Type #tagname in a note to auto-add the tag
  • Use the tag input bar below the title for explicit tags
  • Click a tag in the sidebar cloud to filter your notes
  • Tags appear in the note list for quick scanning

06

Think Spatially on Canvas

The Infinite Canvas is a spatial whiteboard where you can place note cards anywhere, creating visual arrangements of your ideas.

  • Click Canvas in the sidebar to open
  • Select the Note tool then click to place a card
  • Drag cards to reposition them
  • Scroll to zoom in/out on the canvas
  • Pan with the Select tool to explore
